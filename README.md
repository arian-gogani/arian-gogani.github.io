# arian-gogani.github.io

The personal site for Arian Gogani, generated from the canonical public profile data in [`arian-gogani/arian-gogani`](https://github.com/arian-gogani/arian-gogani/blob/main/data/profile.json).

The checked-in HTML contains the latest verified snapshot for search engines and no-JavaScript clients. The browser also fetches the canonical data file so measured GitHub counts can update without creating a second source of truth.

## Verify locally

```sh
python3 tests/test_site.py
python3 -m http.server 8000
```
